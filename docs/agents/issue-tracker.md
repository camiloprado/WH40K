# Issue tracker

Este repositório usa **GitHub Issues** em https://github.com/camiloprado/WH40K/issues.

## Como buscar o spec de origem

1. Nos commits/PR, procurar referências `#N`.
2. Buscar a issue com `gh issue view N` (ou a UI do GitHub).
3. Se não houver issue, o edital técnico é [`SPEC.md`](../../SPEC.md) na raiz.
4. Padrões de código: [`CODING_STANDARDS.md`](../../CODING_STANDARDS.md).

## Code-review

O skill `/code-review` usa este arquivo para localizar o spec da mudança. Sem issue ligada, use `SPEC.md`.
